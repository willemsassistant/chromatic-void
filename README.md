# Chromatic Void

An abstract one-page React/Vite website experiment built around infinite-scroll vibes, layered gradients, orbital forms, and cinematic motion.

## Stack

- React
- Vite
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Concept

This is intentionally not a product site. It is a design study: a surreal, glossy, slightly sci-fi visual composition designed to feel rich and alive while staying lightweight and easy to run locally.
